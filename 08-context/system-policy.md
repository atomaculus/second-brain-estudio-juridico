# Politica Del Sistema

## Objetivo

Mantener un sistema operativo legible, auditable, reversible y cuidadoso con informacion confidencial.

## Fuentes Y Conflictos

- Cada area debe tener una fuente de verdad declarada.
- La ausencia de fuente se marca como ambigua.
- Las contradicciones se registran y escalan; no se resuelven en silencio.
- Los vencimientos requieren fuente oficial, fecha de verificacion y responsable.

## Limites De Agentes

Los agentes pueden ordenar informacion, preparar notas, detectar datos faltantes y redactar borradores. Sin aprobacion explicita no pueden enviar comunicaciones, presentar escritos, modificar sistemas externos, cambiar registros financieros canonicos, mover documentos importantes ni cerrar decisiones juridicas.

## Confidencialidad

- Minimizar copias y datos personales.
- Preferir referencias o resumenes a documentos completos.
- Separar datos vivos de estructura distribuible.
- No usar datos reales como ejemplos, fixtures o pruebas.
