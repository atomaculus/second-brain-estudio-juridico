# Confirmar Carpeta Canonica

1. Leer el registro y las raices autorizadas.
2. Comprobar que la ruta exista o marcarla como propuesta.
3. Revisar aliases, duplicados y posibles colisiones.
4. Confirmar con una persona responsable.
5. Actualizar `confirmed=true` sin mover archivos.
6. Si se requiere reorganizacion, preparar un plan y respaldo separados.
