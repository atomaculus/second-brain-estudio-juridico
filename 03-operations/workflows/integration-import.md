# Importar Desde Un Sistema Externo

1. Exportar o recibir datos por un mecanismo autorizado.
2. Guardar el archivo fuera de Git.
3. Ejecutar el adaptador en modo simulacion.
4. Validar formato, duplicados, faltantes y conflictos.
5. Revisar el staging con una persona responsable.
6. Aplicar solamente los registros aprobados.
7. Conservar una traza minima sin copiar documentos o secretos.
